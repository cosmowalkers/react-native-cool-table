## What This Is

A React Native table component library (`react-native-cool-table`) published as a compound component. Strict TypeScript. Built with `react-native-builder-bob`.

## Commands

```bash
yarn bootstrap          # First-time setup: install deps + iOS pods
yarn lint               # ESLint (pre-commit hook runs this)
yarn typescript         # Type check (pre-commit hook runs this)
yarn test               # Jest tests
yarn prepare            # Build lib/ (commonjs + module + types)
```

CI pipeline: lint -> typescript -> test --coverage -> prepare.

## Architecture

### Compound Component Pattern

`CoolTable` is assembled in `src/index.tsx` as a compound component:

```
CoolTable        = Table component
CoolTable.Cell   = Cell component
CoolTable.Row    = Row component
CoolTable.Sort   = Sort indicator
CoolTable.sortStatus = SORT_STATUS_MAP constant
```

### Two-Context System (Performance Critical)

The table splits React context into two providers to minimize re-renders:

- **TableStaticContext** (`src/context/TableStaticContext.ts`) — rarely-changing values: `columns`, `positionX` (Animated.Value), `treeConfig`, `rowStyle`, `onSortChange`
- **TableStateContext** (`src/context/TableStateContext.ts`) — frequently-changing values: `sortState`, `setSortState`, `expandedKeys`, `toggleExpand`, `isExpanded`

Both are provided by `Table` and consumed by `Row` and `Cell`. This split is intentional — do not merge them.

### Rendering Pipeline

```
Table → Animated.ScrollView (horizontal) → FlatList (vertical, sticky header)
  → Row → columns.map → Cell → Sort
  → renderExpand() (recursive Row for tree children)
```

### Fixed Column Mechanism

Columns with `fixed: true` are sorted to the front. Their cells render as `Animated.View` with `translateX: positionX`, counteracting horizontal scroll to stay pinned.

### Tree/Expandable Rows

Controlled by `treeConfig` prop (`TExpandable`). Expand state is a `Set<string>` of row keys. `toggleExpand` uses `LayoutAnimation`. `autoCollapseOthers` clears other expanded keys on open.

### Sort

Single active sort: `TSortState = { columnKey, sort } | null`. Clicking a sortable header cycles asc -> desc. `onSortChange` callback fires via `useEffect` watching `sortState`.

## Key Rules from AGENTS.md

See `AGENTS.md` for the full coding guide. Critical points:

- **Strict TypeScript** — no `as any`, `@ts-ignore`, or `@ts-expect-error`
- **`import type`** required for type-only imports (`importsNotUsedAsValues: "error"`)
- **Interface prefix `I`**, type alias prefix `T` (e.g., `ITableProps`, `TSortType`)
- **All components**: `memo(forwardRef(...))` pattern
- **Internal handlers**: `_` prefix (`_onPress`), render helpers: `render` prefix (`renderCell`)
- **Lodash** for guards: `isNil`, `isEmpty`, `isFunction`, `isArray` — named imports only
- **Conventional Commits** enforced by commitlint + husky

## All Types in One Place

`src/types/index.ts` is the single source of truth for all shared interfaces and type aliases. Do not scatter type definitions across component files.

## Example App

Located in `example/`. Uses `babel-plugin-module-resolver` to alias `react-native-cool-table` to `../src/index` (live source). Run with `expo start` from `example/` or `yarn example ios` from root.

## Build Output

`lib/` is generated by `yarn prepare` — never edit files there. Three targets: `lib/commonjs/`, `lib/module/`, `lib/typescript/`.
